Task Management Application
Description:
     The Task Management Application is a Full Stack Web Application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. 
It helps users create, update, view, and delete tasks. This project demonstrates CRUD operations, REST API development, and MongoDB database integration.

Features:

1.Create new tasks
2.View all tasks
3.Update existing tasks
4.Delete tasks
5.REST API using Express.js
6.MongoDB database connectivity
7.Responsive and user-friendly interface.

Installation Steps
Clone the repository from GitHub.
Open the project in Visual Studio Code.
Open the terminal.
Go to the backend folder.
Install the required packages using:

npm install

Start the server using:

npm run dev

Open the frontend using Live Server or by opening the index.html file in a web browser.
API Endpoints

GET /tasks - Retrieve all tasks

POST /tasks - Create a new task

PUT /tasks/:id - Update an existing task

DELETE /tasks/:id - Delete a task

Output

The application allows users to:

Add new tasks
Display all tasks
Update task details
Delete completed or unwanted tasks
